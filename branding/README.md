# Logo Liconex aprobado

Creado con la herramienta integrada de generación de imágenes (modo built-in), sin API externa.

- Presentación aprobada: `liconex-presentacion.png`.
- Logo horizontal transparente: `../dist/assets/liconex-logo.png`.
- Símbolo cuadrado verde/marfil: `../dist/assets/liconex-icon.png`.

Concepto: monograma L y perímetro protegido entrelazados. Verde profundo #344d43, marfil #f6f5f0 y salvia #74816a. El archivo horizontal es PNG con transparencia; no se presenta como archivo vectorial.

Brief final de generación: identidad sobria para Liconex, seguridad electrónica en Uruguay, con símbolo geométrico de una L integrada en un perímetro abierto, tipografía sans serif, texto «Liconex» y descriptor «SEGURIDAD ELECTRÓNICA», sin escudos, candados, cámaras ni efectos tridimensionales. Después de la aprobación se extrajeron el logo horizontal sobre transparencia y el símbolo invertido sobre verde, usando la imagen aprobada como referencia y pidiendo conservar su geometría y proporciones.
